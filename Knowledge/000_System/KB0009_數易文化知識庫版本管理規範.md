# 建立目的

本知識庫將持續擴充。

所有生命密碼知識，均依照數易文化課程內容逐步建立。

本知識庫為唯一正式版本（Single Source of Truth）。

所有AI回答，皆必須引用本知識庫。

不得引用其他來源。

---

# 知識更新原則

每一次新增知識時：

不得修改既有規則。

不得推翻舊規則。

應新增新的Markdown。

若原有知識需要修正，

更新Version即可。

例如：

Version：

1.0

↓

1.1

↓

2.0

保留更新紀錄。

# 更新方式

當老師新增課程內容時：

建立新的Markdown。

例如：

KB0210

KB0312

KB0410

......

而不是修改舊知識。

避免AI引用舊Embedding。

---

# 相容性原則

所有新版知識，

必須向下相容。

不得因更新而造成：

AI無法回答。

Embedding失效。

搜尋不到資料。

---

# Metadata規範

每篇Markdown必須包含：

id

title

category

version

priority

tags

related

author

created

updated

status

其中：

status：

draft

review

published

正式使用：

published

# AI引用規則

若同一主題：

存在：

Version 1.0

Version 2.0

Version 3.0

AI永遠優先引用：

Version最高。

不得引用舊版本。

---

# 禁止事項

不得：

直接刪除知識。

不得：

覆蓋歷史版本。

不得：

引用未發布版本。

draft：

不可引用。

review：

僅老師測試。

published：

正式引用。
