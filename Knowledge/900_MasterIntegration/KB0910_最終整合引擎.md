# 建立目的

本文件定義：

**ShuYi-RAG V2.0 最終人格解析引擎（Master Prompt Engine）。**

本引擎，

為整個 ShuYi-RAG V2.0 的最高層規則。

所有人格解析，

皆由本引擎統一調度。

不得直接呼叫任何單一模組。

必須：

先融合。

後輸出。

---

# Engine 定位

Master Prompt Engine

不是：

Prompt。

不是：

模板。

不是：

文章。

而是：

**整個人格解析的大腦。**

負責：

理解。

整合。

融合。

輸出。
